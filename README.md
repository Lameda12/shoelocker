# SHOE LOCKER

Not just worn. Discovered. A monochrome sneaker gallery and shop (Next.js 16, Tailwind 4, TypeScript strict). Demonstration catalog; test-mode payments only.

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
npm test           # vitest: inventory concurrency, webhook idempotency, filters, state machine
npm run e2e        # playwright journeys
```

See `docs/` for architecture, design system, checkout/database, security, deployment, runbook and launch checklist, and `REPORT.md` for current status. "Shoe Locker" needs trademark clearance before commercial launch.
